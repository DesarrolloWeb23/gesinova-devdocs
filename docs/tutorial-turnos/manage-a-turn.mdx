# Gestion de turnos

Permite la administracion y gestion de los turnos generados por la sede

## Llamado del turno

El usuario puede usar dos formas para realizar el llamado del usuario, ya sea por medio del boton "Llamar" que se encuentra en la parte inferior,
este lo que hará será tomar el primer turno que se encuentra en el listado y lo llamará automaticamente.

![Llamado de turnos](/img/Turnos/turnos_3.png)

Tambien podria hacerlo al seleccionar el turno el turno desde la tabla y luego dar clic sobre el boton amarillo "Llamar" que se encuentra a la derecha

![Llamado de turnos](/img/Turnos/turnos_4.png)

Luego de realizar el llamado del turno, es posible rellamar al afiliado o realizar la cancelacion del turno

![Llamado de turnos](/img/Turnos/turnos_15.png)

El usuario puede filtrar los turnos de la tabla para verificar por prioridad

![Llamado de turnos](/img/Turnos/turnos_14.png)



## Cancelacion del turno

El usuario puede realizar la cancelacion del turno, sea cual sea el estado en el que se encuentra es posible cancelarlo.
Se debe seleccionar el turno o tener en atencion para que sea posible cancelar el turno.

![Cancelacion de turnos](/img/Turnos/turnos_5.png)

Debe seleccionar el motivo por el cual va a realizar la cancelacion del servicio para que le permita continuar.

![Cancelacion de turnos](/img/Turnos/turnos_10.png)



## Transferencia del turno

Al momento de realizar la atencion del turno es posible realizar transferencia del turno, lo que nos permite darle otro turno al usuario 
para que sea atendido por otra area u otro colaborador.

![Transferencia de turnos](/img/Turnos/turnos_6.png)

Si el turno no se ha gestionado o no se ha atendido al afiliado, te va a generar un error, ya que el turno debe encontrarse "en atencion" para ser transferido

![Transferencia de turnos](/img/Turnos/turnos_7.png)

Al momento de querer transferir el turno puede desplegar las diferentes areas a las que desea transferirlo y debe guardar cambios

![Transferencia de turnos](/img/Turnos/turnos_8.png)

El sistema le va a generar un nuevo turno el cual va a poder seleccionar o llamar directamente para hacer la respectiva atencion.

![Transferencia de turnos](/img/Turnos/turnos_9.png)

## Atencion del turno

Luego de crear el turno y realizar el llamado, el usuario puede generar la atencion del afiliado, a este punto se debe cambiar el estado del turno.
Esto con la finalidad de que sea posible contabilidad el tiempo que se demora con el afiliado y llevar un mejor control sobre la informacion.

![Transferencia de turnos](/img/Turnos/turnos_12.png)

El sistema va a empezar un contador el cual le va a mostrar la cantidad de tiempo que lleva con el afiliado.

![Transferencia de turnos](/img/Turnos/turnos_13.png)
