# Generacion de turnos

Puedes generar turnos para afiliados y registrar personas para la creacion de un turno.


## Creacion de turnos para afiliados

Se debe ingresar el tipo y numero de cedula del afiliado, seleccionar una prioridad y dar clic en **Validar**
El sistema traerá la informacion del afiliado y debes seleccionar el tipo de servicio que desea.

![Creacion de turnos](/img/Turnos/turnos_1.png)

## Creacion de turnos para NO afiliados

Para la generacion de turnos para usuarios que no se encuentran en la base de datos, se debe realizar el ingreso
de tipo y numero de documento, se selecciona la prioridad y se da clic en **Validar**

**Se debe ingresar el primer nombre y primer apellido obligatoriamente para poder continuar**

![Creacion de turnos](/img/Turnos/turnos_2.png)
