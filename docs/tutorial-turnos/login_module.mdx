# Ingreso al modulo

para el ingreso al modulo es posible usar dos opciones, que serian por el acceso rapido que se encuentra en la ventana principal

![Ingreso](/img/Turnos/turnos_16.png)

**Si la opcion de ingreso no se encuentra en acceso rapido es porque no has ingresado al aplicativo por primera vez**

Si no encuentras el acceso rapido es posible ingresar por la barra lateral desplegandola y seleccionando la opcion para el modulo de Turnos
