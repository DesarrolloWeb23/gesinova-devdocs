# Tutorial Intro

Gesinova un aplicativo integral, con acceso a varios modulos que nos permite gestionar sistemas de informacion.
Puedes realizar el ingreso y/o recuperacion de la contraseña de acceso en https://gesinova.pijaossalud.com/

## Inicio de sesion

Para ingresar al aplicativo debes realizarlo con  **usuario de Gemanet** y la contraseña que hayas configurado.

![Login](/img/login.png)

Si aun no cuenta con una contraseña puedes realizar el restablecimiento de contraseña en  **[¿Olvidaste tu contraseña?](https://gesinova.pijaossalud.com/)**.

## Restablecimiento de contraseña

Para el restablecimiento de la contraseña se debe ingresar el correo asignado y dar clic en **Enviar código**
Al correo electronico le llega un codigo con el que va a hacer el login para luego hacer cambio de contraseña por una personal

![restablecimiento de contraseña](/img/reset_password.png)

## Cambio de contraseña

Para realizar el cambio de contraseña luego de hacer el inicio de sesion,
debes ingresar a **Gestion de perfil** y encontrarás la opción para cambio de contraseña.

![cambio de contraseña](/img/change_password.png)

Debes ingresar la contraseña actual, confirmarla e ingresar la nueva contraseña.

![cambio de contraseña](/img/change_password_2.png)
